# mahakpunjabi.github.io

Personal portfolio website of Mahak Punjabi, biomedical engineer.

Live at https://mahakpunjabi.github.io

The site is plain HTML, CSS and JavaScript, served by GitHub Pages from `main`. Push to `main` to update the live site.

- `index.html` is the homepage: intro, projects with the Industry / MedTech and Research / PhD order toggle, skills, leadership, about and contact.
- `projects/` holds one case study per project. Each follows the same seven sections (overview, objective, contribution, design process, testing and validation, results, takeaways) around a scroll-driven animation.
- `css/site.css` holds all the styles. The light and dark color tokens are at the top.
- `js/site.js` fades sections in on scroll and reorders the project cards.
- `js/scene.js` runs the scroll animations on the project pages.
- `img/` holds photos and figures, and `img/cards/` the homepage card images in light and dark versions.
